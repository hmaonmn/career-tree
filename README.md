# ◈ Career Tree — система карьерного развития

Интерактивная платформа, которая помогает сотруднику:
1. Создать профиль (имя, отдел, направление, грейд)
2. Заполнить ключевые навыки — Hard, Soft и Проектные
3. Увидеть карту своих умений и варианты карьерного роста
4. Выбрать цель развития и получить персональный сценарий с действиями

**Стек:** чистый HTML + CSS + JavaScript. Без сборки. Данные хранятся в `localStorage`.

---

## 🚀 Быстрый старт

### Локально
Откройте `index.html` двойным кликом. Либо через сервер (рекомендуется):
```bash
python3 -m http.server 8000
# http://localhost:8000
```

### GitHub Pages
1. Загрузите файлы в репозиторий.
2. Settings → Pages → Source: Deploy from a branch → main / (root).
3. Через минуту откройте `https://<username>.github.io/<repo>/`.

## 🎯 Пользовательский сценарий

### 1. Онбординг (3 шага)
- **Шаг 1** — имя, отдел, направление (Backend/Frontend/Data/DevOps/Product/QA), грейд (Junior→Principal)
- **Шаг 2** — оценка навыков слайдерами в трёх группах (Hard / Soft / Проектные). Кнопки быстрого заполнения: «Новичок» (20), «Средне» (50), «Уверенно» (75)
- **Шаг 3** — проверка данных + показ стартовой позиции и готовности к следующей ступени

После создания профиля пользователь попадает на главную страницу.

### 2. Профиль
- Аватар, уровень, XP
- Текущая позиция + следующая ступень + готовность
- Все навыки в 3 колонках с возможностью прокачки через «+»

### 3. Роза навыков
- Графический радар по 3 режимам (Hard / Soft / Проектные)
- Границы Junior / Middle / Senior наложены на текущие значения
- Таблица «Вы / Junior / Middle / Senior» с подсветкой разрывов

### 4. Карта роста
- Сетка «направление × грейд» — 30 позиций
- Подсветка: текущая позиция, вертикальный рост, горизонтальные переходы, выбранная цель
- **Дерево карьерных переходов** — визуальные маршруты от текущей позиции
- Клик по ячейке/узлу → модалка с требованиями, разрывом в навыках и выбором цели

### 5. План развития
- Если цель не выбрана — 3 рекомендации с наибольшей готовностью
- Если цель выбрана — сценарий:
  - Готовность, количество пробелов, оценка срока
  - Навыки, отсортированные по величине пробела
  - Рекомендации для каждого навыка (курсы, практика, менторство)
  - Кнопка «+ В план» добавляет действие в список целей
- Достижение цели (готовность ≥ 100%) → кнопка «Перейти на позицию»

### 6. Активность
Хронология событий: прокачка навыков, добавление целей, смена позиции.

## 🧱 Модель данных

```
Track (6 направлений) × Grade (5 грейдов) = 30 позиций
Skill Catalog: 29 Hard + 5 Soft + 7 Project = 41 навык
```

**Готовность к позиции** = среднее по `min(1, текущий / требуемый)`.

**Сценарий развития** — построение пробелов по целевой позиции с сортировкой по убыванию разрыва и рекомендациями по типу навыка (Hard → курсы/практика/ментор, Soft → фидбэк/митапы, Project → ownership/ретро).
